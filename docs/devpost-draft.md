## What it does

Financial OS is a personal finance tracker that skips forms entirely. You type or speak — in English or Bahasa Indonesia — natural phrases like "spent 20 on coffee" or "bayar listrik 1.250.000". The parser understands intent: it rejects plans ("i want to buy a bike") and cancellations, so your journal reflects what actually happened.

The core innovation is the **Ethical Surplus** model. Financial OS calculates surplus only after obligations are covered — never touching principal savings. Users predict next week's surplus (Surplus Oracle), and when validated, route 10% to a vetted cause via **PayPal Payouts** with explicit two-step confirmation. No auto-donate, no guilt tripping.

Everything is visual: journal, ledger with 36 filter combinations, PDF exports, Bryntum Gantt-powered long-term goals, and a scoped AI assistant that explains the app but refuses coding, off-topic, and jailbreaks.

## How we built it

Backend is Fastify 4 + TypeScript on Render, connected to Neon Postgres, Upstash Redis, and Elastic Cloud. The parser is pure and deterministic (40/40 unit tests), handling USD and IDR, negation, and intent rejection. PayPal Payouts uses a TypeScript SDK generated by **APIMatic** from PayPal's OpenAPI spec, sandbox mode.

Frontend is Next.js 14 App Router on Vercel, with server components for data and a `/api/proxy` route for client-side calls — solving Next.js's strict `NEXT_PUBLIC_*` env boundary. Design tokens follow a Stripe-inspired light palette with PayPal accent (#0070ba). Bryntum Gantt 8 renders financial goals with custom fields.

The AI assistant is scoped by design: prompt embeds a versioned canary; output scanned before returning to client (500 + alert on leak). Model pinned: `google/gemini-3.8-flash` via OpenRouter.

## Challenges

- **Next.js client env boundary**: `process.env.API_URL` undefined in client components. Solved with proxy route, zero CORS.
- **Render free-tier cold start** (~50s): auto-retry 3×4s + warm-up UX.
- **Peer dep mismatch**: `@fastify/cors@11` crashed Fastify 4. Pinned to v9.
- **Model ID normalization**: OpenRouter rejects IDs without `provider/` prefix. Pinned in code.

## Accomplishments

- **Multiple AI touchpoints**: text parser, voice, scoped assistant, PDF export
- **Meaningful PayPal integration**: Payouts with two-step confirm, not a "Donate" button
- **Ethical model**: principal savings untouched, human-in-the-loop enforced
- **Full-stack end-to-end**: Vercel + Render + Neon + Upstash + Elastic, zero localhost

## What we learned

- **Model IDs need provider prefixes**. Pin in code, alias in env = broken.
- **Auth at session start ≠ auth mid-session**. Verify before every remote op.
- **Peer deps are silent landmines**. Check matrix before `pnpm add`.
- **Cold start is a UX problem**. Pre-warm must be a feature.
